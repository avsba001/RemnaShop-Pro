# V3.9.0 — 通用 HTTP 服务与支付宝在线支付

保留 V3.8.2 的 Remnawave Panel 3.4.8 / contract 3.4.15 兼容与写请求不自动重试策略。

## 功能

- Compose 增加独立 aiohttp `http` 服务，默认只绑定宿主机回环端口。
- ZPAY 支付宝 API 下单、HTTPS 收银台二维码、GET 异步通知、服务端查单补偿。
- 全部套餐按 CNY 定价；冻结整数分金额、套餐内容和默认内部组快照。
- 通用支付账本按商品类型/业务单号关联记录，可挂载其他商品路由；当前自动交付仅实现订阅。
- 收款确认后后台自动新购/续费，重复支付通知、重复点击不重复发放。
- 暂时隐藏 USDT、人工审核新购入口及 USDT 价格输入/展示，保留历史订单及字段。
- 安装成功条件扩展为 Bot 和 HTTP 两个容器都 healthy；运维日志/重启涵盖两个服务。

## 安全与限制

- 回调验签及商户、订单、金额、支付方式和交易号校验，拒绝重复查询字段。
- 网关交易号唯一约束；到账事件事务提交后才答复 success。
- 不假定网关创建超时代表失败，不自动重放下单；未知交付不再次 Extend。
- 未实现退款、支付关闭/过期、跨商户迁移，也没有开放匿名下单 API。
- 收银台 GET 不写网关；可信代理提供真实 IP，随机能力链接、HTML 转义和 POST 校验。
- 改善 SQLite 查询/执行异常路径的连接关闭，避免异常后占用数据库文件。

配置及上线检查详见 [支付接入文档](../zpay-payments.md)。
