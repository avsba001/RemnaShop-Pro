# V3.8.2

目标更新为 **Remnawave Panel 3.4.8**（2026-11-08 核对的最新稳定版）。
官方发布源码仍声明 `@remnawave/backend-contract` **3.4.15**。
部署方式仍为 Docker Compose；安装和卸载入口不变。

## API 兼容性

- 下载并保存官方 `info.version=3.4.8` 的 OpenAPI，更新契约来源、运行时调用
  清单、开发约束、版本常量、启动日志和机器人内契约提示。
- 全量比较 3.4.4 与 3.4.8：162 个路径、218 个操作、309 个 Schema 完全一致，
  仅 OpenAPI 标题和版本元数据变化；未引入推测路由或新字段。
- 新增机器可读契约锁文件和离线版本、文件哈希、结构指纹校验。
- 保留 2.x 到 3.x 的数值用户 ID 迁移、安全绑定及歧义记录处理。

## 写入安全

修复通用 HTTP 客户端原先默认重试所有方法的问题。网络异常或 429/5xx 后，
Panel 可能已经执行写操作；同一次订单处理中的底层 HTTP 重试会绕开外层
状态保护。现在所有 POST/PUT/PATCH/DELETE 均只尝试一次，安全读取仍最多三次。
已有安全批量状态赋值的持久化重试保留，不确定的破坏性任务仍进入 `unknown`。
